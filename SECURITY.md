# Security and preship maintenance

Do not commit environment files, API/database credentials, customer exports, cookies or production snapshots. Use the host's secret store. Report a suspected exposure privately through Clinch Valley Digital's contact channel; do not include live credentials or customer data in public issues.

Run secret/history checks before making repositories public. Review dependencies and relevant browser/security tests after changes. No test should send real messages, charge a card, seed customer data or run production migrations.

The October 26, 2026 review is scoped evidence, not a security/compliance certification. Reassess collection, remote resources, asset rights, claims and accessibility when behavior changes. Owner: Kevin / Clinch Valley Digital; the actual business owner controls business/privacy decisions.
